# Pharsight V1 文档入口

> 当前进展（2026-09-22）：已在保持 FinSight 总体架构不变的前提下，完成医药双模式代码适配，并以真实 189 页公司年报跑通完整解析、489 块持久索引、任务检索、分析和 11 节 Markdown 研报。下一步是 Python 3.11、多来源/行业案例和领域人工验收。图检索与 Claim–Evidence RAG 复用现有页级证据边界继续演进。

V1 的目标不是一次性完成完整医药研报系统，而是用一个范围受控、证据可核验的场景，先跑通 FinSight 现有三段式主流程：

```text
研究任务书 -> DataCollector 采集 -> DataAnalyzer 分析
           -> ReportGenerator 生成带引用报告 -> 发布校验
```

在此基线上，再演进到“文档解析、信息抽取、Claim–Evidence 构图和混合检索”。
